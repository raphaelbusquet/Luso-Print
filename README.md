# Lusoprint

Atelier de design e impressão 3D sediado em Lisboa. Este repositório contém o site oficial da Lusoprint — uma loja online de decoração feita à mão, com peças personalizáveis para casa e família.

Construído com Vite + React + TypeScript. Backend em Supabase (autenticação, armazenamento de imagens geradas). Deploy em Vercel.
